# DepOwl Website

This is the landing page for depowl.ai, featuring Allie the Owl.

## Viewing Locally

### Option 1: Open directly in browser
Simply open `index.html` in your web browser.

### Option 2: Use a local HTTP server
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (install http-server: npm install -g http-server)
http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000`

## Deployment

This site is automatically deployed to GitHub Pages from the main branch.

Live URL: https://depowl.github.io/website/ (or your custom domain)
